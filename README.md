## Project Overview
The goal of this project is to predict house prices in California using a variety of machine learning models. The dataset contains features such as median income, house age, and location (latitude and longitude). The project demonstrates how data is prepared and different models are evaluated to predict prices accurately.

## Dataset
The dataset used for this project is the [California Housing Dataset](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html), available through `sklearn.datasets`. It contains the following features:
- `MedInc`: Median income in the block group.
- `HouseAge`: Median house age in the block group.
- `AveRooms`: Average number of rooms per household.
- `AveBedrms`: Average number of bedrooms per household.
- `Population`: Total population in the block group.
- `AveOccup`: Average number of household members.
- `Latitude`: Latitude of the block group.
- `Longitude`: Longitude of the block group.
